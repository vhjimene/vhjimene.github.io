# 👨‍🎓 Portafolio Académico - Víctor Hugo Jiménez Benítez

Sitio web personal que presenta la trayectoria académica, investigativa y profesional de un Doctor en Psicología especializado en psicología social, comunitaria y política.

## 📋 Secciones

- **Inicio**: Presentación profesional
- **Perfil Académico**: Resumen de formación y especialización
- **Líneas de Investigación**: Áreas de estudio y enfoque
- **Publicaciones Científicas**: Artículos, manuscritos en revisión y en preparación
- **Competencias Metodológicas**: Métodos cuantitativos, cualitativos y software especializado
- **Experiencia Profesional**: Gestión pública, docencia e investigación
- **Redes Internacionales**: Colaboraciones académicas a nivel internacional
- **Contacto**: Enlaces de comunicación y plataformas académicas

### Modificar estilos

En `styles.css`, busca las variables CSS:

```css
:root {
    --primary-color: #1e40af;      /* Azul principal */
    --secondary-color: #3b82f6;    /* Azul secundario */
    --accent-color: #06b6d4;       /* Color acento */
    --text-color: #1f2937;         /* Color texto */
    --light-bg: #f0f9ff;           /* Fondo claro */
}
```
